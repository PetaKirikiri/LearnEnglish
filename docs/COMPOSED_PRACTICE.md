# Composed listening practice

The journey uses `GeneratedPractice` for Levels 1–5 and the same component inside each Level 6 star. Every set has 30 distinct spoken prompts and two choices. Level 4 combines its limited taught action-question pattern with earlier location-question review. Existing historical question banks remain scoring archives and teaching fixtures.

`generatedPracticeContent.ts` enumerates valid requests to the shared sentence engine, using the taught catalogue and excluding `a`, `an`, `it` and `to`. Alternatives preserve the construction and change one semantic component: person, ownership, noun/number or compatible action. Question IDs include the level and a deterministic sentence/contrast hash; shuffling answer positions does not change the registered answer.

`generatedPracticeProgress.ts` chooses a seeded, balanced round using account progress and locally saved evidence. Vocabulary uses one account-wide profile and unlock queue, independent of level or star. The shared starter families are man, woman, boy, girl, mother and father, plus existing practice knowledge. Levels apply grammatical compatibility to that shared inventory; they never seed their own nouns. Old per-level defaults are ignored unless supported by actual practice evidence. Correct visible exposure can fade scaffolding, but does not unlock vocabulary. Three independent correct decisions with the tested contrast and its revealing agreement cues hidden establish listening mastery. Audio must have ended; help or replay prevents mastery credit. Only the tested contrast receives server proficiency credit. A wrong decision removes local mastery and restores support for recovery. One new noun family is introduced at a time; it must be learned before the next. Already known words remain review. Previously heard sentences are avoided when eligible alternatives exist.

The run, its answer IDs, current presentation snapshot, assistance/replay count and evidence are stored per account. Refresh resumes the same set and cannot erase assistance. Guest learning remains local; authenticated answers use the existing durable outbox and server receipt system. Local and server success totals are combined without adding the same success twice.

Level 6 retains three gated stars, now 30 questions each. Two unassisted 27/30 passes unlock the next star. Star 2 introduces holding, then opening, then washing after listening evidence on each prerequisite; preliminary rounds still contain 30 questions but cannot clear the tier before all three actions are represented. Previous 50-question star passes are retained and best scores are proportionally converted. Journey completion aggregates the three stars as 90 questions.

Run `node --import tsx scripts/prepareGeneratedPractice.ts` to build the exact audio index and additive scoring catalogue. It reuses existing recordings by normalized spoken sentence and writes missing recording requests to `/tmp/english-generated-audio.json`. Generate those with `scripts/generateNeuralAudio.py` using the documented local Kokoro environment. Keep the shared voice and verify every indexed audio file before release. Apply the additive composed-question and round-shape migrations before publishing the client. The original journey-clears migration must also be present.

Checks cover counts, uniqueness, randomized balanced positions, taught scope, staged actions, mastery gates, agreement cues, account isolation, refresh/help/replay persistence, complete 30-question runs, historical score migration and exact audio/scoring registration. Broader test typechecking currently has unrelated existing errors in actionDialogue, classOne, demoRace and PracticePatternExplanation tests.

## Everyday vocabulary revision

`src/learning/everydayVocabulary.ts` now owns the practical noun priority, action order, description contrasts and the explicit irregular people forms. These priorities are teaching judgements, not corpus-frequency measurements. The shared starting pool is man, woman, boy, girl, mother and father. Family words follow before professional roles. Historical encounters and proficiency remain available; old list membership alone is not mastery.

Actions use their own shared listening evidence and introduction order. Compatible level frames still constrain selection. Noun success does not prove a verb. Later levels include six short noun-meaning checks per set, and reserve decisions that actually test the action; this avoids blocking mastery of single-object verbs such as drinking water. Star 1 includes familiar bare actions, so Level 6 can use the shared people-first starting inventory without adding holding or food merely to fill its questions.

Description contrasts open after a noun has listening evidence: red/blue, big/small, hot/cold, green/yellow, black/white. Each pair must be recognised before the next pair opens. Both alternatives use the same familiar noun. Action-description sentences also require recognition of their verb. Existing number/agreement and action-question sets retain their structural focus; description variants use the noun-phrase, location-question and action-answer constructions. Going-to-destination remains outside scored practice until its preposition/construction is taught; warm/cool are not yet added.

New people and actions have tightly framed pictures. Family vocabulary uses a relationship context with the target family member enlarged. Simple colour, size and temperature marks are code-native SVG. This is implementation coverage, not proof of picture-only comprehension with students. Review at `/vocabulary-review.html` shows only the noun, verb and description lists, sourced directly from this curriculum module.

The vocabulary profile namespace is v4; current rounds remain v3 and account evidence keys remain unchanged. The additive `20261110000400_everyday_curriculum.sql` and `20261110000600_people_first_vocabulary.sql` register new questions while retaining historical question IDs. Retired questions must not be deleted; the audit compares the current active ID set while allowing the scoring archive to retain earlier versions.

The source-informed priority review and remaining content gaps are recorded in `docs/VOCABULARY_PRIORITY.md`.
