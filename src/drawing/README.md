# Classroom Game

Teacher: `/classroom/index.html` → Students (existing QR) → Game. Student attendance and LINE identity are reused. Start drawing opens the game on all joined phones. One student is enough to test the full round. The default drawing time is 60 seconds; 30/90/120 are also available.

Each participant receives one private Thai noun from their practised course vocabulary, with recorded attempts in their own word-progress data. There is no unscored fallback; if a participant has no eligible words, starting the round fails without assigning anyone a word. Drawings autosave during the timer, with a tab-local backup. Tap Ready to submit and lock the drawing. Server-recorded finishing bonuses are +3/+2/+1 for the first three, once per round. Autosaves do not count as finishes. All players finishing advances the round early; otherwise the server ends drawing time. Teacher presents each picture with “What is this?”; students answer aloud “That is a/an …”. The question and drawings stay on the classroom screen. Phones show only waiting, the full-screen canvas, names to award a point, then names for the favourite-picture vote. Answers are spoken. Only the current artist can award one point to another round participant. Awarding reveals the English answer; the teacher can reveal without a point and advance past absent artists.

After all pictures, the computer shows the whole gallery and “ใครวาดภาพได้ดีที่สุด?”. Each participant votes once for another nonempty picture. Teacher closes voting. All tied winners receive three points; no votes means no bonus. Scores accumulate across rounds in this class, separately from practice coins. Late joiners can watch; they participate from the next round. “Return phones to class” hides the game; reopening resumes it.

Backend: `supabase/migrations/20261110000500_drawing_game.sql`. Tables are RLS-protected with no direct participant grants. The RPC checks the existing class host secret / authenticated attendance, locks the session, validates phases and round IDs, and filters private prompts. The follow-up drawing migrations add solo play, course vocabulary and finish submissions; `20261110001000_drawing_scored_vocabulary.sql` removes unscored fallbacks; do not apply unrelated pending migrations.

Students scan once on the Students tab. The shared `english_class_activity` state routes their existing class page between Testing, Game and the whiteboard waiting screen. Testing and Game have no join QR or external practice link. `/english/game/preview` remains a separate standalone preview with a scan-first QR screen. Scanning opens `/english/game/preview?phone=1` and only then starts the automatic phone test, without signing in or saving points. Browser classroom joins start LINE login and retain the class query through the return URL.

Checks: `npx vitest run src/drawing src/classroom/session.test.ts`. `integration.sql` exercises a two-student game; `finish.integration.sql` checks finish ranks, bonuses, retries, frozen submissions and deadline enforcement. `flow.integration.sql` verifies personal scored words, rejection without partial assignments when a learner has none, private prompts, all-ready advancement, every picture, artist-only credit and final voting/scoring. All SQL tests roll back their fixtures and progress changes; run through the project's privileged SQL management connection. Physical phone and classroom Wi-Fi conditions still need in-room confirmation.
